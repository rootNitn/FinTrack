# Personal Finance & Investment Tracker — Frontend

Angular 19.2 single-page application for the Personal Finance & Investment Tracker. This is the
`frontend/` half of a monorepo; the API server lives in `../backend` (Node + Express + TypeScript +
Prisma + PostgreSQL).
 
## Features

- **Dashboard** — net worth, income/expense summary, upcoming reminders at a glance.
- **Investments** — buy/sell tracking, SIPs, CSV import/export, investment comparison tool.
- **Transactions** — unified read-only ledger across all money movements.
- **Expenses & Income** — categorized entries with recurring expense support (EMI, insurance, etc.)
  and split-expense tracking with a "Split Balances" view to see who owes you and mark splits settled.
- **Bank Accounts & Credit Cards** — balances, statements, payments, rewards/cashback tracking.
- **Fixed Deposits** — FD calculator, portfolio tracking, maturity/renewal/rate-change alerts.
- **Goals** — savings goals with contribution tracking and achievement notifications.
- **Calculators** — SIP, EMI, and other financial calculators.
- **AI Features** (`/ai-insights`) — rule-based spending analysis, savings opportunities, budget
  alerts and portfolio insights computed from your own data (no external LLM call).
- **Analytics** (`/analytics`) — income vs. expense trends, expense heatmap, savings rate, net worth
  growth, investment performance, category-wise spending, year-over-year growth.
- **Upcoming Bills** (`/upcoming-bills`) — a unified, sortable timeline of upcoming SIPs, EMIs,
  insurance premiums, credit card dues, and FD maturities across a 7/30/90-day window.
- **Reports** — monthly/quarterly/yearly/investment/expense/goal reports with Excel/CSV/PDF export.
- **Notifications** — SIP due, EMI due, credit card due, goal achieved, budget exceeded, FD maturity,
  FD rate change, higher FD rate available, FD renewal reminder, insurance renewal, and (optional)
  birthday reminders, generated by backend cron jobs and individually toggleable in Settings.
- **Settings** — preferred currency (applied app-wide to every amount displayed), notification
  preference toggles, and other account preferences.
- **Admin Dashboard** (`/admin`, admin-only) — overview KPIs, user management (activate/deactivate,
  change roles), and an audit log viewer.

## Prerequisites

- Node.js `20.11.1` (or a version satisfying Angular 19's `^18.19.1 || ^20.11.1 || ^22.0.0` range).
- The backend API running locally (see `../backend/README.md` or the root `package.json` scripts)
  on `http://localhost:4000` — the frontend dev server proxies/points to this by default.

## Development server

From the monorepo root, you can start both backend and frontend together:

```bash
npm run dev
```

Or, to run just this frontend app, from this `frontend/` directory:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

## Tech stack

- Angular 19.2 (standalone components, signals)
- Angular Material + Tailwind CSS
- ECharts (via `ngx-echarts`) for all charts/analytics visualizations
- RxJS + Angular `HttpClient` for API communication with the backend

## Project structure

```
src/app/
  core/        # guards, interceptors, services (auth, api base, toast, etc.), shared models
  layout/      # app shell, sidebar, navbar
  shared/      # reusable components (data-table, chart-card, confirm-dialog, etc.) and utilities
  features/    # one folder per feature (dashboard, investments, expenses, analytics, notifications, ...)
```
